## 📌 Proyecto destacado

### 📡 Network Monitor — mini hacker ético
> Herramienta en Python que monitorea la conexión a internet en tiempo real.

- ✅ Ping a IPs (8.8.8.8, 1.1.1.1)
- ✅ Detección de caídas y latencia
- ✅ Guardado de resultados en `.txt`
- 🔧 Escalable a dashboard Flask + alertas por Telegram

```python
import os, time

while True:
    r = os.system("ping -n 1 8.8.8.8")
    print("✅ Conexión activa" if r == 0 else "❌ Sin conexión")
    time.sleep(5)
```
